# Nexus Genius — Genius Certify

Plataforma SaaS multi-tenant para emissão, gestão e validação de certificados digitais.

## Estrutura

```text
.
├── frontend/     # React + Vite + TypeScript + Tailwind
├── backend/      # FastAPI + SQLAlchemy + PostgreSQL (em breve)
├── .gitignore
└── .cursorrules
```

## Frontend (dev local)

```bash
cd frontend
npm install
npm run dev
```

## Backend / Docker

Em breve: `docker compose` com FastAPI, PostgreSQL e MinIO.
